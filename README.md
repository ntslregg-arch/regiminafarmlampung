# REGI MINA FARM LAMPUNG

Website resmi REGI MINA FARM LAMPUNG untuk menampilkan produk ikan air tawar, galeri farm, promo, keranjang, checkout, pembayaran, testimoni, dan pelacakan pesanan.

## Struktur Folder

```text
REGI-MINA-FARM-LAMPUNG/
├── index.html
├── README.md
├── css/
│   └── style.css
├── js/
│   └── script.js
└── assets/
    ├── images/
    │   ├── farm-background.png
    │   ├── gallery-1.png
    │   ├── gallery-2.png
    │   └── gallery-3.png
    └── banners/
        ├── banner-1.svg
        ├── banner-2.svg
        ├── banner-3.svg
        └── banner-4.svg
```

## Upload ke GitHub

1. Buat repository baru di GitHub.
2. Upload seluruh isi folder ini.
3. Pastikan `index.html` berada di folder utama repository.
4. Untuk GitHub Pages, buka **Settings → Pages** lalu pilih branch utama dan folder `/ (root)`.

## Catatan

Website menggunakan `localStorage`. Data yang diubah melalui panel Admin tersimpan pada browser/perangkat yang digunakan dan belum menjadi database online bersama.
